# Moved to [phassle/mods](https://github.com/phassle/mods)

These skills now live in **[phassle/mods](https://github.com/phassle/mods)**, together with phassle's Claude Code mods. This repository is archived and gets no updates.

```bash
npx skills@latest add phassle/mods                    # skills.sh
claude plugin install phassle --marketplace phassle/mods   # Claude Code plugin
```

In the plugin, `tokenomics` is now `/phassle:tokenomics`.
